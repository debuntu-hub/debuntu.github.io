R

期待値最大化プロジェクト

投資成績分析システム

目的 データ仕様 分析 運用

日本株 現物取引に最適化

1トレードあたりの期待値（平均R）を最大化する

過去の取引履歴と市場データを統合し、再現可能な高期待値トレードだけを実行するための仕様書です。月次・四半期での継続的な改善を前提とした運用設計を示します。

固定損切り -8% 平均Rで評価 定期見直し

基本前提

  • 対象：日本株（現物）
  • 損切り：-8% 固定
  • 期待値：平均R = 実現リターン(%) ÷ 8%
  • 1トレード：残高が0に戻るまでを1行で管理

Purpose

目的

上手くいった／ダメだったトレードを定量的に分類し、期待値が高い条件のみを抽出して投資ルールへ落とし込みます。感覚的な売買判断を排除し、再現可能なプロセスを重視します。

期待値の定義

R = 実現リターン(%) ÷ 8%
期待値 = 平均R

トレードの成否は平均Rで測定し、0を下回る条件は採用しません。

Architecture

システム全体構成

  1. 証券会社の約定履歴を整形
  2. トレード正規化（1トレード=1行）
  3. J-Quantsの日足データを結合
  4. 特徴量を付与（地合い・出来高・ギャップ率など）
  5. 期待値分析・条件評価
  6. 投資方針・ルールを更新

Data Specs

データ仕様

トレード正規化ルール

  • 1トレードの定義：同一銘柄でBuyにより残高が正になってから、Sellで0に戻るまで。
  • 分割エントリー・分割利確は同一トレードに統合。
  • 処理順：exec_datetime昇順。同一日時は入力順。
  • 損益計算：pnl_yen = Σ(sell_price×qty) − Σ(buy_price×qty) − fee_amount
  • pnl_pct = pnl_yen ÷ buy_amount
  • R = pnl_pct ÷ 8%
  • Sell先行や残高マイナスは不整合として除外。

約定データ（証券会社）

  • trade_fill_id, code, side (Buy/Sell)
  • exec_datetime, price, quantity, fee
  • account_type (NISA/特定/一般)

トレードデータ（分析用）

  • trade_id, code, entry_date, exit_date
  • avg_entry_price, avg_exit_price
  • buy_amount, sell_amount, fee_amount
  • pnl_yen, pnl_pct, R, holding_days
  • peak_exposure（任意）

市場データ（J-Quants）

  • date, code, open/high/low/close
  • volume, adj_close

市場環境データ

  • index: TOPIX
  • close, ma_25
  • trend_flag: 上昇 / 下落

データ品質チェック

  • Sell先行や残高マイナスの検知
  • 手数料集計（約定単位→トレード単位）
  • タイムゾーン/日付のずれを正規化

Feature Engineering

特徴量設計（エントリー時点）

52週高値更新フラグ 直近高値ブレイク種別 出来高急増率（当日 ÷ 過去20日平均） ギャップ率 ATR 移動平均乖離率 地合いフラグ（TOPIX×25MA）

Analysis

分析仕様

基本指標

  • トレード数 / 勝率 / 平均リターン(%)
  • 平均R（期待値）
  • 連敗数（任意）

条件別期待値分析

特徴量ごとにグループ分けし平均Rを算出

  • 出来高 ≥ 2倍 / < 2倍
  • 地合い良 / 悪
  • ブレイク種別別 など

Operation

投資方針と定期見直し

投資方針への落とし込み

  • 平均R ≤ 0 の条件は採用しない
  • 平均Rが高い条件のみを組み合わせ（最大3つ）
  • 目的は「トレード数削減」ではなく「期待値最大化」

定期見直し運用

月次または四半期で実施

  1. 直近期間の条件別平均Rを再計算
  2. 期待値が低下した条件を1つ削除
  3. 新条件を1つだけ追加して検証（同時変更は避ける）

Output

最終アウトプット

投資条件一覧

採用中の条件とその平均Rを明示し、実行可能な売買ルールとして管理。

資産曲線・期待値推移

期間ごとの平均Rの変化を可視化し、ルールの陳腐化を検知します。

次期検証テーマ

改善の仮説を1つだけ設定し、検証と学習を繰り返します。

Goal

再現可能な高期待値トレードのみ実行

Data-driven investing for resilient performance.
